# Geometry Crash

Аркада-выживалка в жанре «survivors»: герой ходит по полю 800×600, оружие стреляет само по
ближайшим врагам, с убитых падают кристаллы опыта, при повышении уровня игра ставит паузу и
даёт выбор карт. Цель — прожить 10:00 **и** убить босса. Если к 10:00 босс жив — поражение.

Реализована идея A из `PROJECT_IDEA.md`. Идею B («Крестики-нолики++») из приложения не делаем.

## Запуск

```powershell
python -m venv .venv           # если окружения нет
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Запуск без venv: `python main.py` (нужен Python 3.12.x и pygame 2.6.1).

В `.venv` проекта pygame 2.6.1 установлен (`pip install -r requirements.txt`), там Python
3.12.7. Проверки и запуск делались и на `.venv`, и на системном Python 3.12.10 — оба с pygame.

Экран, шрифты и графика — только примитивы pygame, внешних ассетов и файлов шрифтов нет.
Весь текст на экране русский (язык по умолчанию) и переключается на английский пунктом
«Язык» в меню; язык и фулскрин сохраняются между запусками в `settings.json`. Кириллицу
рисует цепочка системных шрифтов (Segoe UI / DejaVu / Arial / Liberation), при её отсутствии
— встроенный шрифт pygame без падения.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение (220 px/с); в меню W/S тоже двигают выделение |
| Space | рывок: 120 px, откат 1,5 с, 0,25 с неуязвимости |
| 1 / 2 / 3 / 4 | выбор карты при повышении уровня (4 = карта слияния) |
| Enter | в меню — открыть пункт; в паузе — продолжить; с итогов — в меню |
| Esc | пауза; с подэкранов меню (Управление/Рекорды/Книга) — назад в меню |
| Up / Down | выбор пункта меню (Enter — открыть, мышь — тот же клик) |
| M | звук вкл/выкл |
| R | рестарт партии |
| F11, Alt+Enter | полноэкранный режим (флаг сохраняется в `settings.json`) |
| Мышь (ЛКМ) | клик по кнопкам меню, подэкранов, паузы, итогов и карт level-up |

Оружие стреляет автоматически, цель — ближайший враг.

## Что реализовано

- 10 базовых оружий (пистолет, огненная аура, цепная молния, косилька, морозные шипы, ледяная
  зона, ракеты, стрелы, турель-спутник, бомба-липучка), уровни 1..8: +30% урона, +15%
  скорострельности, +1 цель на уровнях 4 и 7.
- 6 типов поведения оружия (снаряд, аура, цепь, дуга, спутник, бомба-зона), 22 варианта
  (10 базовых + 12 гибридов) используют их с разными параметрами.
- 12 фиксированных слияний. Слияние доступно, только если оба оружия уровня ≥ 3; оно заменяет
  оба оружия одним гибридом (уровень = больший из двух), гибрид занимает 1 слот и повторно не
  сливается. Открытые связки видны в «Книге связок» (12 слотов) на экранах стартовом и итоговом.
- 8 пассивок (скорость, урон, крит, радиус подбора, реген, щит, площадь, откат), каждая до 3
  уровней, аддитивный стек; редкость карт 60/30/10 (обычная, редкая ×1,5, эпическая ×2,
  цветная надпись). Сундук каждые 2 минуты даёт гарантированную эпическую пассивку.
- Слоты: максимум 6 оружия и 6 пассивок. Карты level-up: 3 обычные + 4-й картой слияние,
  без дубликатов; при нехватке вариантов карт меньше; когда пул пуст — резервные карты
  (+20 HP, +10 скорость, +10% урон).
- Волны каждые 30 с, лимит живых врагов по минутам 6/10/14/20/28/40/55/70/80/90, спавн порциями
  по 10 в секунду у границ поля. 8 типов врагов + элита (с 5-й минуты), босс (с 8-й минуты) с
  тремя фазами: погоня, кольцевой залп из 12 пуль, призыв 6 минионов. На время боя босса поле
  очищается, обычный спавн останавливается, возобновляется после его смерти.
- Огненные зоны с телеграфом 1,5 с, горят 4 с, 5 урона/с, до 3 одновременно; источник —
  планировщик спавна в `waves.py` (единственный источник событий волн/зон/сундука).
- HP 100, контактный урон (ползун 5, танк 10, спринтер 12, босс 15) с кулдауном 0,5 с на каждого
  врага; кристаллы опыта (1 XP, с 4-й волны 2 XP) и радиус подбора 60 px.
- Знаменщик даёт соседям +25% скорости, танк выталкивает мелких врагов на 20 px, делитель
  распадается на 2 малых, прыгун скачет рывками, спринтер телеграфирует линию рывка.
- HUD: таймер, HP, XP, уровень, номер волны, число врагов на поле, убийства, счёт связок,
  полоса босса, откат рывка, список оружий и пассивок. Полоска заряда рывка под персонажем
  (36×5 px) показывается только пока рывк откатывается; готов — скрыта. Экраны: главное меню,
  Управление, Рекорды (топ-10), Книга связок, level-up, пауза, итоги.
- Главное меню: Играть, Язык (ru/en, сохраняется), Во весь экран (сохраняется), Управление,
  Рекорды, Книга связок, Выход; навигация стрелками/W-S + Enter и клик мышью. Фулскрин
  F11/Alt+Enter: сцена 800×600 масштабируется с letterbox, координаты мыши пересчитываются
  в логические. Язык и фулскрина переживают перезапуск (`settings.json`).
- Между партиями сохраняются только топ-10 рекордов и «Книга связок» (`records.json`), плюс
  язык и фулскрин (`settings.json`). Улучшения игрока в новую партию не переносятся.
- Визуальные эффекты: частицы при смерти, вспышки взрывов, дуги, тряска экрана.
- Звук: 4 синтезированных гудка (убийство, level-up, босс, сундук) через `pygame.mixer`,
  без файлов ассетов. M переключает звук, состояние видно в HUD. Если аудио-устройства нет,
  игра работает без звука.
- Локализация: весь видимый текст (меню, HUD, карты, баннеры, причины смерти, имена оружий,
  связок и пассивок) живёт в `locale.py` и берётся из таблиц ru/en; перевод меняется сразу,
  язык — по умолчанию русский.

## Плейтесты (фактические результаты)

Полные 10 минут гонялись headless-автопилотом (dt=0.05, реальный игровой цикл, реальный выбор
карт, реальный спавн и босс, реальный HP — без неуязвимости). Все случайные события идут из
игрового rng (`game.rng`), поэтому seed воспроизводит один и тот же забег. Режимы автопилота:
`1` (блуждание), `kite` (отступление от толпы и зон), `pro` (отступление + пара под слияние),
`elite` (отступление + карты выживания: скорость/щит/реген + пара), `lane` (бег вдоль стен —
толпа тянется следом, карты выживания + пара).

| Агент | Смерть | Убийства | Уровень | Связки |
|---|---|---|---|---|
| случайное блуждание (слабый игрок, режим `1`) | 2:25 / 2:26 / 2:48 / 3:11 | 208-587 | 5-10 | 0 |
| отступление от врагов и зон, карты по приоритету урона (`kite`) | 3:18 / 4:53 / 4:56 / 5:20 | 302-917 | 6-12 | 0 |
| отступление + фокус на паре для слияния (`pro`) | 3:36 / 4:19 / 6:32 + победа 10:00 на seed 3 | 584-4645 | 9-34 | 1-2 |
| отступление + карты выживания (скорость/щит/реген) + пара (`elite`) | 3:39 / 5:18 / 6:19 + победа 10:00 на seed 2 | 431-4545 | 8-41 | 0-1 |
| бег вдоль стен + карты выживания + пара (`lane`, сильный агент) | 6:26 (seed 4) + победа 10:00 на seed 1, 2, 3 | 1524-4811 | 18-42 | 1-2 |

Итог по балансу (DoD 5): смерть типичной первой партии — 2-3,5 минут у слабого игрока, 4-5 минут
у среднего, 6+ минут и выход на босса у сильного; 5 из 20 seed-ов закончены победой (босс убит
до 10:00, уровень 34-42, 1-2 найденные связки). Медиана смерти сильных агентов по 6 seed-ам
в проверке — 6:00, смерть среднего агента (seed 11) — 4:20, обе в целевой полосе 4-6 минут.
Все цифры воспроизводимы: `ARENA_SEED` задаёт поток случайных событий, повтор seed-а даёт тот же
забег (в проверке determinism: два одинаковых seed-а в одном процессе и в разных процессах
совпадают по кадрам).

Условия победы проверены дополнительно:
* Скриптованный сфокусированный забег (игрок неизуязвим, всегда берёт карту пары pistol+chain
  и карту слияния) получил карту слияния на 4:40 (уровень 13) — середина забега, не конец.
* Скриптованный полный 10-минутный забег закончился экраном победы: босс убит, рекорд записан,
  Книга связок обновилась (`test_logic.py`, test_full_run).
* Реальный автопилот с реальным HP: `test_logic.py`, test_skilled_agent — seed 1 закончил 10:00
  с убитым боссом (4203 убийства, уровень 39, 1 связка), босс убит минимум на 2 из 6 seed-ов,
  медиана смерти и смерть среднего агента — в целевой полосе 4-6 минут.
* DPS фокусной сборки 3-го уровня (arc_pistol Lv3 + Fire Aura Lv3 + пассивка урона 20%) = 92.5,
  босс 500 HP умирает за 5.4 с — целевое «~30 DPS, 15-20 с» из ТЗ превышено с запасом.

FPS меряется отдельно: headless-забег с `ARENA_DT` идёт без pacing, поэтому `avg_fps` в строке
теста не показывает реальный FPS. Прогон 900 кадров с обычным pacing (`clock.tick(60)`) дал
60,6 FPS при dummy-драйвере; на нормальном запуске частота ограничена теми же 60. Запас по
производительности измеряется в `test_logic.py` (update+draw при 90 живых врагах
~1,5 мс на кадр при лимите 16,7 мс).

Автопилот для полного цикла (один 10-минутный забег, ~12 секунд реального времени):

```powershell
$env:SDL_VIDEODRIVER="dummy"; $env:ARENA_AUTOPLAY="lane"; $env:ARENA_DT="0.05"; $env:ARENA_TEST_FRAMES="12600"; $env:ARENA_SEED="1"; python main.py
```
(режимы: `1` = случайное блуждание, `kite` = отступление, `pro` = отступление + фокус на паре,
`elite` = отступление + карты выживания, `lane` = бег вдоль стен + карты выживания + пара;
seed 1, 2, 3, 7 в режиме `lane` заканчиваются победой)

Запуск без автопилота, 15 секунд headless: 60 FPS, спавн и автострельба работают. При отсутствующем
аудио-устройстве (`SDL_AUDIODRIVER` невалиден) игра запускается и работает без звука
(в проверке `sound=False`). При первом запуске без `records.json` игра стартует с чистыми
рекордами и книгой.


## Чего нет (антископ из документа)

Магазин, валюта, мета-разблокировки, сеть, камера/прокрутка, процедурная генерация, внешние
ассеты и файлы шрифтов, упаковка в exe. Камеры нет: поле статично 800×600. Пространственная сетка не
нужна: наивный перебор при 90 врагах даёт ~1,6 мс на кадр (60 FPS с запасом).
Попадания снарядов и исключения таргетов хранят ссылки на объекты врагов, а не `id()`:
переиспользование адресов dead-врагов ломало воспроизводимость seed-а (проверено построчно).
